# Grupp 1 - BookClubExamination

### Projektbeskrivning

- Vi har skapat en sida åt en bokklubb.

Den riktar sig till alla "bokmalar" 📚 som vill vara med i en bokklubb för att t.ex. få tips på böcker att läsa, kunna läsa eller skriva recensioner och även lägga upp egna tips på sidan som andra kan ta del av.

Det krävs att man har ett konto på sidan om man önskar kunna lägga upp böcker och skriva recensioner. Man skapar lätt sin profil genom att registrera sig och man kan när som helst ändra sina uppgifter eller avsluta sitt konto i profildelen. Som gäst kan du alltid söka och hitta böcker samt läsa skrivna recensioner.

Admin till sidan så som t.ex. återställa lösenord, rensa i databasen etc. sköts i Strapi i detta projekt.
